# A1-2 Python 응용: API 활용 국내 여행지 추천 프로그램 개발  
## 1. 프로그램 개요  
사용자가 특정 날짜를 입력하면, 해당 시기에 방문하기 좋은 국내 여행지를 대규모 언어 모델(LLM)이 추천하고,  
추천된 지역의 맛집 정보를 지도/장소 검색 API로 찾아 최종 여행 리포트를 자동 생성해 주는 CLI(Command Line Interface) 기반 파이썬 프로그램  
또한 동일한 날짜에 프로그램을 다시 실행할 경우, 기존에 저장된 데이터를 활용하여 Gemini와 Kakao API를 다시 호출하지 않도록 캐싱 기능을 구현  


- - -

## 2. 주요 기능  

### 1) CLI 기반 실행  
\- *Python*의 *argparse*를 활용하여 터미널에서 프로그램을 실행할 수 있도록 구현  
\- 사용자는 다음과 같은 형식으로 원하는 여행 날짜를 입력  

```text
python travel_planner.py --date "YYYY-MM-DD"
```

\- 날짜가 필수 입력값으로 설정되어 있으며, 날짜 형식이 올바르지 않은 경우 사용법을 출력하고 프로그램을 종료하도록 입력값을 검증  

### 2) LLM 기반 맞춤형 여행지 추천  
\- 사용자가 입력한 날짜를 *Gemini API*에 전달하여 해당 시기의 여행 지역을 추천하도록 구현  
\- LLM이 자유로운 형태의 문장을 출력하지 않고 다음과 같은 JSON 구조로 결과를 반환하도록 프롬프트 설계  

```text
recommended_city: 추천 지역
weather: 해당 시기의 날씨 요약
events: 행사 및 축제 후보
reason: 추천 근거
```
\- 위와 같이 구조화된 JSON 형식을 사용하여 다음 단계인 맛집 검색 API의 입력값으로 활용할 수 있도록 구성  

### 3) 지도/장소 API 연동 맛집 검색  
\- 1차 추천 결과에서 recommended_city 값을 추출하여 *Kakao Local API*에 검색어로 전달하고 해당 지역의 맛집을 검색  
\- 검색 결과에서는 맛집 이름, 주소, 카테고리, URL, 좌표 등의 정보를 수집하도록 구성  
\- 검색 결과가 없는 경우에도 프로그램이 중단되지 않고 맛집 정보를 데이터 없음으로 처리하여 다음 단계인 최종 리포트 생성까지 진행하도록 구현  

### 4) 최종 여행 리포트 생성  
\- 1차 여행지 추천 결과와 *Kakao Local API*에서 검색한 맛집 목록을 *Gemini API*에 전달하여 최종 여행 리포트 생성  
\- 최종 리포트에는 다음과 같은 내용을 포함하도록 프롬프트를 구성  

```text
추천 지역
추천 이유
날씨 요약
행사 및 축제 목록
맛집 추천
1일 일정 제안
오류 요약
```

### 5) 결과 데이터 저장
\- 프로그램 실행이 완료되면 results/ 폴더에 실행 날짜를 기준으로 결과 파일을 저장하도록 구현  
\- 원본 JSON에는 다음 정보를 포함  

```text
1차 여행지 추천 결과
맛집 검색 결과
오류 목록(errors)
```
\- 최종 여행 리포트는 Markdown(.md) 파일로 저장하여 프로그램 실행 결과를 쉽게 확인할 수 있도록 함

## 3. 사전 준비 및 API 키 설정

### 1) 필요 환경  
| 구분 | 환경 및 도구 | 용도 |
|:---:|:---:|:---:|
| 프로그래밍 언어 | Python 3.10 이상 | 프로그램 개발 및 실행 |
| 개발 도구 | Visual Studio Code | Python 코드 작성 및 실행 |
| LLM API | Google Gemini API | 여행지 추천 및 최종 여행 리포트 생성 |
| 장소 검색 API | Kakao Local API | 추천 지역의 맛집 검색 |
| 버전 관리 | Git | 소스 코드 변경 이력 관리 |
| 원격 저장소 | GitHub | 프로젝트 코드 저장 및 관리 |
| 실행 환경 | 터미널(CLI) | 프로그램 실행 및 진행 로그 확인 |

\- 프로그램은 별도의 웹 UI 없이 **터미널에서 실행할 수 있는 CLI 방식**으로 구현  

### 2) API 키 설정 방법
\- *Gemini API*와 *Kakao Local API*를 사용하기 위해 각각의 API 키를 발급받아 '.env' 파일에 저장  
\- 프로젝트 폴더에 '.env' 파일을 만들고 다음과 같이 API 키를 설정  

```text
GEMINI_API_KEY="YOUR_GEMINI_API_KEY"
KAKAO_API_KEY="YOUR_KAKAO_API_KEY"
```

\- .env 파일에 API 키를 저장하고 .gitignore 에 등록하여, 소스 코드와 Github 저장소에 실제 API 키가 노출되지 않도록 관리
